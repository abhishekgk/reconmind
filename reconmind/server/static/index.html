Toolbox

API keys

Add whatever keys you can afford — each one unlocks more sources. Keys are stored locally (chmod 600) and wired straight into the right tool configs on save. Leave blank to skip a service.

Compare with a previous scan

See what's new or gone since an earlier scan of the same target — new subdomains, live hosts, IPs, open ports and endpoints are where fresh bugs live.

📡 Monitoring

Watch a target on a schedule — ReconMind re-runs recon every N hours in the background and highlights what's new (subdomains, live hosts, endpoints, takeover candidates) since the last run. New attack surface is where fresh bugs show up. Runs only while the server is up.

Scope allow-list

One host per line — e.g. example.com matches it and every subdomain. While this list is non-empty, recon / Fuzzer / Nuclei refuse out-of-scope targets. Leave it empty to allow any target (default).

Scan history
